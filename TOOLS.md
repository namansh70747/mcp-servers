### api-tester

_Save & run HTTP requests. add_request, run, run_collection, list_requests, set_env, set_auth, set_assertions, import_curl, import_openapi, history, curl_for._

- `add_request(name, url, method?, headers?, body?, collection?, auth_type?, auth_value?, assertions?)` — Save a request into a collection. Optional auth (bearer/basic/apikey) and assertions.
- `curl_for(request_id)` — Emit an equivalent curl command for a saved request (round-trips with import_curl).
- `delete_env(env, key?)` — Delete one variable, or the whole environment when key is empty.
- `delete_request(request_id)` — Delete a saved request.
- `export_collection(name?)` — Export a collection to a ready-to-paste JSON document of its saved requests.
- `get_env(env?)` — List variables for an environment (values returned as-is; treat as local secrets).
- `health()` — Liveness check: confirm this server is running and reachable.
- `history(request_id?, limit?)` — Recent run history — all requests, or just one when request_id is given.
- `import_curl(command, name?, collection?, save?)` — Parse a curl command into a request. Saves it by default; set save=False to just preview.
- `import_openapi(spec, collection?, limit?)` — Import an OpenAPI/Swagger JSON spec (file path or URL) — creates a saved request per operation.
- `list_envs()` — List all environment names that have variables.
- `list_requests(collection?)` — List saved requests.
- `replay(history_id, env?)` — Re-run a request captured in run history.
- `run(request_id, env?)` — Run a saved request (with env-var substitution, auth, and assertions) and record history.
- `run_collection(collection?, env?)` — Run every request in a collection (with the given environment).
- `run_inline(url, method?, headers?, body?, env?, auth_type?, auth_value?, assertions?)` — Run an ad-hoc request without saving it (supports env/auth/assertions).
- `save_response(request_id, path, env?)` — Run a saved request and write its full response body to a file.
- `set_assertions(request_id, assertions)` — Attach response assertions to a saved request.
- `set_auth(request_id, auth_type, auth_value)` — Attach auth to a saved request. auth_type: bearer | basic (user:pass) | apikey (Header:value).
- `set_env(env, key, value)` — Set an environment variable for {{KEY}} substitution. Stored locally in plaintext SQLite.

- `diagnose()` — Full status: WPP engine, which feature modules are present, and what memory has learned.
- `end_call()` — End the active WhatsApp call (best-effort).
- `forget(alias)` — Forget a learned nickname/alias.
- `health()` — Quick readiness: Chrome running, JS-from-Apple-Events on, WPP engine present & ready.
- `job_status(job_id)` — Status/result of a background WhatsApp job.
- `list_chats(limit?)` — List your chats (name, unread, group?).
- `list_groups()` — List your groups.
- `list_jobs(limit?)` — Recent WhatsApp jobs.
- `list_nicknames()` — List learned nicknames/aliases and what they resolve to.
- `list_unread()` — List chats with unread messages.
- `mark_read(contact, exact?)` — Mark a chat as read.
- `memory_digest()` — Everything learned: known contacts, nicknames, tone profiles, recent activity.
- `post_text_status(text)` — Post a text Status/Story.
- `promote_in_group(group, member)` — Make a member a group admin.
- `react(contact, emoji?, exact?)` — React with an emoji to the latest message in a chat.
- `read_chat(contact, limit?, exact?)` — Read the latest messages of a chat (by name/number).
- `refresh_contacts()` — Re-pull your full contact list from WhatsApp into memory.
- `remove_from_group(group, member)` — Remove a member from a group.
- `resolve_contact(query)` — Resolve a name/nickname/number to a WhatsApp contact (fuzzy; returns candidates if unsure).

- `send_media(contact, file_path, caption?, exact?)` — Send an image/video/audio/document by name/number (file from disk, ≤16MB).
- `set_nickname(nickname, target)` — Teach a nickname → person. target = a phone number or an existing contact name.
- `setup()` — How to enable the robust WPP engine (one-time).
- `start_call(contact, video?, exact?)` — Place a WhatsApp voice/video call (you talk). Best-effort — web calling may be unavailable.
